# 🥪 Бот «Лёгкая еда»

Telegram-бот для студентов и тех, кто любит готовить быстро и просто.
Вы диктуете продукты — бот подсказывает, что из них можно приготовить:
бутерброды, закуски, сытные блюда и вкусняшки.

## Пример

Пишете боту:

```
сыр, колбаса, хлеб
```

Бот отвечает (выдаёт несколько вариантов, отсортированных по совпадению):

> 🥪 Классический бутерброд с сыром и колбасой
> ⏱ 3 мин · Просто · совпадение 50%
>
> 1. Намажьте хлеб тонким слоем сливочного масла.
> 2. Выложите ломтики колбасы.
> ... и т.д.

## Возможности

- **Свободный ввод** — пишите продукты как угодно: «сыр, колбаса, хлеб»,
  «яйца и помидоры», «творог банан мёд». Бот сам разбивает текст
  и распознаёт продукты (включая словоформы: «сыр/сыра/сыром»).
- **Встроенная база** — более **80 блюд**: бутерброды, канапе, омлеты, каши,
  макароны, супы, салаты, блюда из курицы и рыбы, десерты и вкусняшки.
  Работает офлайн, без интернета и сторонних API.
- **Сортировка по совпадению** — вверху самые подходящие варианты.
- **Клавиатура подсказок** — кнопки с частыми продуктами.
- **Команды**: `/start`, `/help`, `/random`.

## Требования

- Python 3.9+
- Пакеты из `requirements.txt`

## Настройка и запуск

### 1. Получить токен бота

1. Напишите в Telegram [@BotFather](https://t.me/BotFather).
2. Команда `/newbot` → придумайте имя и username бота.
3. Скопируйте токен вида `123456:ABC-DEF...`.

### 2. Проект

```bash
pip install -r requirements.txt
```

Создайте файл `.env` в папке `easy_bot` (рядом с `.env.example`):

```
BOT_TOKEN=ваш_токен_сюда
```

### 3. Запуск

```bash
python -m easy_bot.bot
```

Бот работает через поллинг — просто держите этот скрипт запущенным.
Чтобы остановить — `Ctrl+C`.

## Как это работает (кратко)

- `easy_bot/data/recipes.py` — база рецептов (легко дополнять своими).
- `easy_bot/matcher.py` — разбор введённого текста и сопоставление
  продуктов с рецептами.
- `easy_bot/bot.py` — Telegram-бот на aiogram.

Добавить новый рецепт очень просто: допишите словарь в список `BUNDLE`
в `data/recipes.py` — и он сразу начнёт предлагаться.
